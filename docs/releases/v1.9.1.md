# v1.9.1

`v1.9.1` 是一次安全加固版本：修复了单个匿名请求就能让服务退出的问题，把「全站隐私」改为服务端强制，并加强了登录与加密文章的防爆破。**建议所有部署尽快升级。**

## 安全修复

- **单个请求导致服务退出**：登录请求不带 User-Agent 时，服务端会因未处理的异常退出；all-in-one 部署下整个容器（含数据库）随之重启，且可反复触发。现已修复，并为未处理的 Promise 拒绝增加兜底日志，不再让进程退出。
- **body-parser 升级到 2.4.0**：修复压缩请求体尾部带多余字节时进程退出的问题（GHSA-27r3-jxmh-p828）。
- **全站隐私改为服务端强制**：此前该开关只在浏览器里跳转，服务端仍会输出完整内容，直接请求或不执行脚本的爬虫可以拿到全文。现在开启后：
  - 未登录访问前台页面会跳转到后台登录页，登录后自动返回原页面；
  - 公开接口、RSS、sitemap、搜索索引、自定义页面对未登录访客返回 401；
  - 私有模式下的响应一律标记为不可被 CDN 缓存，开启时自动清理 Cloudflare 缓存。
- **防爆破**：
  - 后台登录失败次数限制改为默认开启（同一 IP 每分钟 3 次），计数改为原子操作，并发请求无法绕过；
  - 另加一条常开的兜底限额：同一 IP 10 分钟内超过 10 次登录尝试会被暂时拒绝，即使关闭了上面的限制也生效；
  - IPv6 地址按 /64 网段计数；
  - 不存在的用户名与错误密码的响应耗时一致，无法据此探测用户名；
  - 加密文章解锁按真实文章计数，`02`、`002` 这类 ID 别名不再绕过每分钟 5 次的限制。
- **访问日志不再记录凭证**：Caddy 访问日志去掉 `Token`、`X-Debug-Super-Token` 等请求头，以及 URL 中的 `token` 参数。
- **登录跳转**：登录后的跳转地址只允许本站，不再跳转到外部网站。

## 行为变化

- 后台「系统设置 → 高级设置 → 登录安全策略」中的失败次数限制开关恢复可用，默认开启。
- 后台登录后会额外写入一个 `vanblog_token` Cookie（`SameSite=Lax`），用于在开启全站隐私时访问前台；登出时一并清除。
- 开启全站隐私后，图片、字体、音乐等媒体文件仍可通过地址直接访问（登录页需要使用；文件名为内容哈希）；评论服务（Waline）不在此次拦截范围内。

## 升级提示

- 本版本不新增数据库结构迁移；升级前备份现有数据库与部署配置。
- 旧版本的 Caddy 访问日志（`log/vanblog-access.log*`）可能明文记录了后台登录凭证。升级后建议在后台登出一次使旧凭证失效，并删除这些旧日志。
- 全站隐私依赖服务端与网站容器共享的内部密钥（`VANBLOG_ISR_TOKEN` 或 `WALINE_JWT_TOKEN`），Docker 部署会自动生成，无需额外配置。

## 发布与部署

- 发布 `caddy`、`server`、`website`、`admin`、`waline` 及 `all-in-one` 六类镜像。
- 每类镜像同步不可变版本标签、版本别名和 `latest`，生产使用带提交 ID 的版本标签。
