# v1.8.2

`v1.8.2` 是一次 Markdown 展示补丁发布，修复首页文章卡片中的列表缩进异常，以及正文和编辑器预览中的窄表格左对齐并占满整行问题。

## 修复内容

- 首页 Markdown 摘要在整体裁剪前规范化顶层列表共同的 1～3 个前导空格，避免首行被 `trim()` 提前顶格、后续行仍保留缩进而形成视觉层级差异。
- 保留嵌套列表的相对缩进，不处理四空格缩进代码、代码围栏和引用块中的列表文本。
- Markdown 表格改为按内容宽度布局并水平居中，不再由 `display: block` 默认占满整个正文宽度。
- 表格仍限制在正文容器内；内容超过可用宽度时继续提供横向滚动，避免撑破桌面端或移动端页面。
- 前台基础 Markdown 样式、公开导出样式、后台编辑器样式和可选 Markdown 主题 hotfix 使用同一套表格布局规则。

## 用户体验

- 首页文章卡片中，同一级列表的首项与后续项目保持一致缩进。
- 列数较少或内容较短的表格会整体居中，不再在右侧留下类似“补齐到文章宽度”的大块空白。
- 内容较多的宽表格仍可横向滚动，现有边框、斑马纹、明暗主题与单元格换行行为保持不变。
- 后台编辑器预览与前台正式文章采用一致的表格宽度策略。

## 兼容性与升级

- 无数据库迁移。
- 无环境变量变更。
- 无 Compose 拓扑变更。
- 可直接从 `v1.8.1` 升级到 `v1.8.2`。

## 验证

- Server 单元测试覆盖顶层列表、嵌套列表、代码围栏、缩进代码、引用块和 `<!-- more -->` 截断。
- Website 测试覆盖三份基础 Markdown CSS、主题 hotfix 以及包含 `<br>`、粗体和中文内容的表格渲染。
- 指定 all-in-one 测试环境完成首页预览、文章正文、后台静态资源与健康检查验收。
- 完整发布门禁使用 `pnpm test:full` 验证。
