# v1.7.0

`v1.7.0` 是一次功能版本，为编辑器与前台渲染管线引入多图表渲染、扩展 Markdown 语法、PDF 导出与阅读体验增强，并将 Kroki 图表服务纳入默认编排。

如果只用一句话概括：

> `v1.7.0` 让 VanBlog 的 Markdown 能画 20+ 种图表（PlantUML/GraphViz/D2/WaveDrom 等）且亮暗色观感统一，支持脚注/高亮/上下标/缩写/合并单元格表格，文章可一键导出 PDF，文章页新增字数统计、阅读时长与顶部阅读进度条。

## 本版摘要

- 新增 Kroki 伴生容器与 PlantUML 专用渲染服务（兼容无 AVX2 指令集的宿主机），server 提供带缓存的代理端点 `POST /api/public/diagram/render`
- 前台与后台编辑器支持 plantuml / graphviz / d2 / wavedrom / vegalite / ditaa / nomnoml / blockdiag 系列等图表语言，附 SVG/PNG 下载
- 图表暗色主题统一：Mermaid 使用自定义 themeVariables（蓝灰系），Kroki 图表默认浅色渲染 + 前端柔和滤镜，圆角卡片观感一致
- 扩展 Markdown 语法：脚注、`==高亮==`、`H~2~O` 下标、`X^2^` 上标、`*[缩写]:` 定义、`||`/`^` 合并单元格表格；后台预览、前台、RSS 三端渲染一致
- RSS 输出改为服务端渲染图表 SVG，阅读器内可直接看图
- 后台文章列表新增「导出 PDF」（浏览器打印方案，内联主题样式与图表）
- 前台文章页元信息新增字数统计与阅读时长（中英文分开计数），顶部新增阅读进度条
- 草稿弹窗支持内联新建文章分类，与文章页行为对齐
- 修复 BackToTop 组件在 document 捕获阶段截断滚动事件、导致 TOC scrollspy 等 window 层监听间歇失灵的历史问题

## 相比 v1.6.6 的变化

如果你已经在使用 `v1.6.6`，这一版最直接的变化是：

- **compose 编排新增 `kroki` 伴生服务**（含 all-in-one 入口），不启动 kroki 时图表代码块优雅降级为普通代码显示，其余功能不受影响
- 文章里的 ```plantuml / ```graphviz / ```d2 等代码块会渲染成矢量图，暗色模式下自动转为柔和深灰配色
- 文章页顶部出现渐变阅读进度条，元信息行多出「N 字 · 约 M 分钟」
- 后台文章列表操作里多出「导出 PDF」

## 部署注意事项

`kroki` 与 `kroki-plantuml` 是伴生容器，不打进 all-in-one 镜像：

```yaml
services:
  vanblog:
    environment:
      VANBLOG_KROKI_URL: http://kroki:8000
      VANBLOG_PLANTUML_URL: http://kroki-plantuml:8080/plantuml
  kroki:
    image: yuzutech/kroki
    restart: unless-stopped
  kroki-plantuml:
    image: plantuml/plantuml-server:jetty
    restart: unless-stopped
```

- Kroki 只在 compose 内网 expose，不对宿主机暴露端口；客户端一律走 server 代理
- PlantUML 走独立的 `plantuml/plantuml-server`：Kroki 内置的 PlantUML 原生二进制要求 CPU 支持 AVX2，老机器上会渲染失败
- PlantUML 中文渲染需要容器内有 CJK 字体，可挂载宿主机字体目录到 `/usr/share/fonts/custom`

如果你使用锁版镜像部署：

```env
VANBLOG_DOCKER_REPO=kevinchina/deeplearning
VANBLOG_RELEASE_SUFFIX=v1.7.0-<image-id>
```

## 升级建议

升级到 `v1.7.0` 后，建议重点验证：

1. 写一篇含 mermaid / plantuml / graphviz / d2 的文章，亮暗色切换下四种图表观感一致（暗色为柔和深灰而非刺眼纯黑或灰白）
2. 脚注、`==高亮==`、上下标、缩写、合并单元格表格在后台预览、前台、RSS 三处渲染一致
3. 后台文章列表「导出 PDF」打印预览包含全部图表且主题正确
4. 文章页字数/阅读时长数值合理，滚动时顶部进度条跟随
5. 不启动 kroki 容器时，图表代码块降级为普通代码块显示且页面无报错

## 回滚方法

如果线上想回滚到上一版，只需要把：

```env
VANBLOG_RELEASE_SUFFIX=v1.7.0-<image-id>
```

改回上一版的 release suffix，然后重新执行：

```bash
docker compose -f docker-compose.image.yml up -d
```

回滚后建议同时停掉 `kroki` / `kroki-plantuml` 伴生容器（旧版不会使用它们）。
