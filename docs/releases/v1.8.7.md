# v1.8.7

`v1.8.7` 是一次前台 Markdown 阅读交互、图表渲染与页面生命周期修复版本。

## 前台

- 统一完整文章和嵌入式 Markdown 的基础样式加载，补齐代码高亮、数学公式和图片缩放样式。
- 代码块默认自动换行，切换按钮能够实际控制换行；主题切换保留展开状态，短代码块不再显示无效折叠按钮。
- 暗色 Markdown 主题的行内代码样式不再覆盖代码块高亮。
- 内容更新和主题切换时重新绑定必要交互，并清理旧代码块事件及图片缩放实例。
- 导航栏、作者卡片和文章目录使用组件自身节点，卸载时清理滚动监听；修复 Headroom 延迟初始化与提前销毁的竞争。

## 图表

- Mermaid 和通用图表保留原始文本，在明暗主题切换时重新渲染。
- 过期异步渲染结果不会覆盖新内容；Mermaid 的全局主题配置与渲染按顺序执行。
- WaveDrom 正确序列化 SVG，应用明暗皮肤，并在安全清洗前将皮肤样式与本地图形引用转换为可保留的 SVG 内容。
- 图表重试、恢复成功或切回已渲染主题时清除旧错误提示，过期请求不会重新写入错误。
- WaveDrom 保留单向箭头、双向箭头和端点，仅接受当前 SVG 内有效 marker 的本地引用。

## 发布与部署

- 发布 `caddy`、`server`、`website`、`admin`、`waline` 及 `all-in-one` 六类镜像。
- 每类镜像同步不可变版本标签、版本别名和 `latest`，生产使用带提交 ID 的版本标签。
- 本版本不新增数据库结构迁移；升级前备份现有数据库与部署配置。
- 部署示例同步至 v1.8.7，版本检查校验示例与根包版本的一致性。
