# v1.9.0

`v1.9.0` 新增「前台屏蔽」功能，并修复了几处公开接口与静态目录的数据暴露问题。**建议所有部署尽快升级。**

## 前台屏蔽

后台 **站点管理 → 系统设置 → 前台屏蔽**，默认关闭。开启后，访客能拿到的所有内容在发出前统一替换，后台始终显示原文。

- **自定义屏蔽词**：关键词（子串匹配，默认不区分大小写，支持批量添加）或正则。
- **内置检测**：API Token / 密钥（`sk-`、`ghp_`、`github_pat_`、`AKIA`、`AIza`、`hf_`、`xox`、`glpat-`、Stripe 等）、私钥块、JWT、URL 中的账号密码、Bearer / Basic 认证头、`password=` 类赋值、邮箱、公网 IP。每项可单独开关，内置检测支持白名单（默认放行 `git@github.com` 等）。
- **屏蔽文本**：按类型区分，默认 `【已屏蔽】`、`【已屏蔽的密钥】`、`【已屏蔽的邮箱】`、`【已屏蔽的IP】`，可修改；会被 Markdown 解析的符号不允许使用。
- **覆盖范围**：文章、动态、关于页、站点信息、社交信息、友链、菜单、客制化代码、标签与分类、搜索与搜索索引、RSS、sitemap、自定义页面、`/static` 下的文本文件（SVG、HTML、JS、CSS、JSON 等）。
- **屏蔽发生在服务端**：在截取摘要、建立搜索索引、渲染 RSS 之前完成，页面 HTML、页面数据和接口 JSON 中都不会出现原文。
- **防试探**：用屏蔽词或其前缀搜索、访问标签 / 分类 / 文章，响应与“不存在”完全一致。
- **链接处理**：路径含屏蔽词的文章改用 `/post/<id>`；含屏蔽词的标签 / 分类显示屏蔽后的名字，并可正常访问。
- **规则变更后**自动清理缓存、整站重新渲染、清理 Cloudflare 缓存并重建 RSS / sitemap / 搜索索引；重建完成前这些文件返回 503，不会输出旧内容。规则无法生效时公开接口返回 503，不会退回原文。
- **试一试与命中扫描**：按未保存的表单规则预览效果；扫描全站命中位置及影响（链接改用 ID、标签重名、页面不可访问、疑似真实密钥）。
- **审计脚本**：`pnpm audit:public-mask` 以访客身份检查公开内容中是否残留屏蔽词，屏蔽词通过环境变量传入。
- 不覆盖：评论、图片中的文字；已被抓取或订阅的旧内容无法收回，真实密钥请直接作废更换。

## 安全修复

- 公开分类文章列表改走公开列表查询，不再返回文章正文和访问密码字段；所有公开接口额外剔除任意层级的 `password` 字段。
- `/static` 改为白名单目录：仅开放 `img`、`music`、`font`、`customPage`、`rss`、`sitemap`、`markdown-themes` 与 `search-index.json`，其余目录（如旧版本遗留的 `blog-json` 备份、`export`、`tmp`）一律返回 404。
- 图片导出压缩包改为写入非公开目录，后台登录后下载。
- RSS 中属于私密分类的文章同样显示为已加密。
- 公开文章列表的布尔参数按字符串严格解析，公开查询的分类 / 标签始终精确匹配。
- 公开缓存中间件路径判断忽略大小写；请求带 `If-None-Match` 时不再按修改时间返回 304。
- 移除无调用方且未过滤动态内容的 `/api/public/search/all`。

## 其他

- 修复思维导图构建覆盖源码入口的问题。
- `/moment`、`/nav` 纳入全站重新渲染；网站 revalidate 接口支持按布局整体刷新。

## 升级提示

- 本版本不新增数据库结构迁移；升级前备份现有数据库与部署配置。
- 若曾使用 v1.8.x 及更早版本，请检查 `static/blog-json/` 是否存在旧备份文件，将其移出 `static` 目录，并轮换其中可能包含的凭据。
- 曾设置访问密码的文章与分类，建议修改密码。
- 若站点经过 Cloudflare 并开启了 Email Obfuscation，启用前台屏蔽后可关闭该选项。

## 发布与部署

- 发布 `caddy`、`server`、`website`、`admin`、`waline` 及 `all-in-one` 六类镜像。
- 每类镜像同步不可变版本标签、版本别名和 `latest`，生产使用带提交 ID 的版本标签。
