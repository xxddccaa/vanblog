# v1.8.8

`v1.8.8` 是一次前台导航栏滚动隐藏行为的修复版本。

## 前台

- 导航栏下滑隐藏时按自身整体高度移出视口，开启分类子菜单后第一行导航与分类栏会一起隐藏。
- 未开启分类子菜单时高度仍为 56px，隐藏距离与之前保持一致，无行为变化。
- 补充回归测试，锁定隐藏位移必须覆盖完整导航高度。

## 发布与部署

- 发布 `caddy`、`server`、`website`、`admin`、`waline` 及 `all-in-one` 六类镜像。
- 每类镜像同步不可变版本标签、版本别名和 `latest`，生产使用带提交 ID 的版本标签。
- 本版本不新增数据库结构迁移；升级前备份现有数据库与部署配置。
- 部署示例同步至 v1.8.8，版本检查校验示例与根包版本的一致性。
