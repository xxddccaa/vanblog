# v1.8.6

`v1.8.6` 是一次前台 Markdown 卡片布局修复版本。

## 前台

- 动态卡片不再继承 Markdown 主题作为完整文档画布时的底部留白，修复卡片底部出现大段空白的问题。
- 首页文章摘要和动态卡片统一使用嵌入式 Markdown 标记，兼容 Plain、JetBrains、PinkHsiao 等带有 `#write` 或 `.markdown-body` 画布样式的主题。
- 服务端首屏渲染、客户端加载动态和刚发布动态的 Markdown 回退路径保持一致。
- 完整文章页、关于页和友情链接说明继续保留正常 Markdown 文档画布布局。

## 验证

- Website Vitest：52 个测试文件、221 个测试通过。
- Website TypeScript 检查通过。
- `git diff --check` 通过。
