# v2.1.1

> 发布日期：2026-11-23

`v2.1.1` 是一次排版修复版本：统一文章正文字号，并收小几套主题里过大的标题。不涉及数据库、配置项和 compose 文件变化。

## 修复

- **手机上正文字号偏小**：文章正文在手机宽度下会继承外层容器的 14px，比文章下方「相关文章 / 最新文章 / 热门文章」列表里的标题（16px）还小。phycat 系列和默认的石墨暗色主题只给段落单独设了 16px，列表仍是 14px，同一篇文章里段落和列表字号不一致。现在所有可选主题的正文在桌面和手机上都是 16px，首页文章摘要同样生效。
- **Plain 暗色主题正文 14px**：Vanblog Plain 暗色主题把正文固定为 14px、行高 1.5，现改为 16px、行高 1.75，与亮色主题一致。
- **标题过大**：
  - Plain 亮色与暗色主题的标题统一为 28 / 24 / 20 / 18 / 16 / 16px（h1–h6）。
  - Minimal（亮色与暗色）、Sepia 暗色、Newspaper 亮色、Candy 亮色的一级标题从 32–35px 收小到 28px。
  - 各主题的配色和装饰不变。

## 升级提示

- 直接换用新镜像即可，无需迁移数据或修改 compose 文件。
- 主题样式地址随版本号更新（`?vbv=2.1.1`），不会读到 CDN 缓存的旧样式文件。

## 发布与部署

- 发布 `caddy`、`server`、`website`、`admin` 及 `all-in-one` 五类镜像。
- 每类镜像同步不可变版本标签、版本别名和 `latest`，生产使用带提交 ID 的版本标签。
