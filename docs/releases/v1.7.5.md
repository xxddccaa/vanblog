# v1.7.5

`v1.7.5` 是一次前台首页阅读体验的小幅增强版本，只改首页文章卡片的预览：把原来的**纯文本摘要**升级为**按 Markdown 渲染**，让粗体、链接、图片、行内代码等在卡片里正常显示。

如果只用一句话概括：

> `v1.7.5` 让博客首页的文章卡片预览不再是「剥光样式的一段纯文字」，而是和文章页同款的 Markdown 渲染——粗体/链接/图片/行内代码都能看到，同时仍是「截断预览 + 阅读全文」，纯代码块或纯图片开头的文章也不再出现空白预览。

## 本版摘要

- **首页卡片按 Markdown 渲染**：前台首页 `OverviewPostCard` 不再把正文剥成纯文本，而是复用文章页同款的 `Markdown` 组件渲染截断后的预览片段，粗体、链接、图片、行内代码、列表等如实呈现。
- **服务端「保留 Markdown 的安全截断」**：新增 `buildArticleMarkdownPreview()`，尊重 `<!-- more -->`（取其之前的部分、不加省略号）；无 more 标记时按**行边界 + 代码围栏感知**截断，绝不切断 ```` ``` ```` 代码块或行内 `[链接]()` / `![图]()`，截断补 `...`，未闭合围栏自动补齐。
- **修复预览空白**：旧逻辑会把代码块 / 图片 / HTML 全部剥除，导致「开头只有代码块或图片」的文章卡片预览为空白；新逻辑保留结构，这类文章预览恢复正常。
- **搜索索引不受影响**：原有纯文本 `buildArticlePreview()` 保持不变，搜索预览仍是纯文本。

## 相比 v1.7.4 的变化

- 前台首页文章卡片预览由纯文本改为 Markdown 渲染；服务端首页预览截断改用「保留 Markdown」的实现。
- 仅涉及前台首页与其对应的服务端预览取数；文章页、归档 / 分类 / 标签页、搜索、后台均保持不变。

## 升级建议

升级到 `v1.7.5` 后，建议重点验证：

1. 打开博客首页，文章卡片预览中的**粗体、链接、图片、行内代码**正常渲染，排版与文章页一致。
2. 长文预览在合适位置截断并出现「...」，点「阅读全文」进入文章页正常。
3. 含 `<!-- more -->` 的文章，卡片预览只显示 more 之前的内容。
4. 开头是代码块 / 图片的文章，卡片预览不再空白。
5. 私密文章卡片仍显示「该文章已加密…」占位，且不泄露正文。

## 回滚方法

纯前台 + 服务端预览取数改动，不涉及数据与配置迁移。把 release suffix 改回上一版并重新 `docker compose -f docker-compose.image.yml up -d` 即可。

锁版镜像部署：

```env
VANBLOG_DOCKER_REPO=kevinchina/deeplearning
VANBLOG_RELEASE_SUFFIX=v1.7.5-<image-id>
```
