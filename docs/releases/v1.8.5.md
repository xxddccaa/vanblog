# v1.8.5

`v1.8.5` 是一次面向数据访问、首屏包体和构建链路的性能与稳定性版本。后端将兼容 record-store、文章搜索、相关文章推荐和公开分类/标签接口进一步下推到 PostgreSQL；前台减少客户端 Markdown 解析；后台编辑器、Emoji 与统计图表改为按需加载。

## 后端与数据访问

- PostgreSQL record-store 兼容查询支持安全的 JSONB 候选下推、排序、分页和计数；不支持的 Mongo 风格条件继续使用完整语义 fallback。
- record-store 更新、删除与 upsert 使用 PostgreSQL 事务、collection advisory lock 和行锁，降低并发覆盖风险。
- 文章浏览量按 pathname / canonical 数字 ID 使用单条原子 SQL 更新，超范围数字安全降级。
- 相关文章推荐在 PostgreSQL 中完成分类、标签和浏览量评分，并保留置顶文章 fallback 顺序。
- 列表视图使用摘要字段，不再无条件读取文章正文。
- 分类与标签公开接口从 N+1 查询改为单文章快照分组，并缓存数据与 `Last-Modified` 元数据。
- 时间线摘要在一次 SQL 快照中返回年份统计与最新时间戳，缓存命中后不再重复加载文章列表。
- 文章搜索增加持久化 `tsvector`、trigram 索引和候选 ID `UNION` 查询；10 万文章测试中稀有词查询不再对文章表执行顺序扫描。
- 文档树与搜索结果移除 JSON stringify/parse 深拷贝，保留树排序、祖先标记和输入不可变。

## 前台

- 首页预览、动态初始内容和友链说明改为服务端 Markdown HTML，客户端 Markdown 仅用于新发布或后续动态加载内容。
- 文章静态参数显式限制为最近 100 篇，冷门文章继续由动态参数处理。
- 独立的布局与页面数据请求并行执行；首页仍保留依赖站点配置的串行流程。
- NavBar 的 Headroom 改为单实例生命周期，不再因菜单开合重复销毁和创建监听器。
- ThemeContext value 保持稳定，移除 Layout 对根 CSS surface 变量的重复写入。
- 服务端 fetch 在按需失效模式下显式使用 `force-cache`；delay 模式默认 60 秒，并尊重调用方显式 `cache` / `revalidate`。
- `/moment` 的页面级 revalidate 配置提升到 60 秒。严格 nonce CSP 与根 layout 动态渲染保持不变，不以 `unsafe-inline` 换取静态化。

## 后台与日志

- 新增可执行的 Vitest + jsdom + Testing Library 单测入口。
- ByteMD 与 Milkdown 按当前偏好按需加载，失败时显示局部错误并支持重新加载。
- Emoji Picker、数据集和中文资源只在打开弹层后加载。
- Welcome 三个统计标签分别异步加载，失败时可在内容区重试。
- 全局后台入口从 Moment 切换到 Day.js；其它仍使用 Moment 的路由级功能保持兼容。
- 文章查询参数改用 `URLSearchParams`，正确处理 `&`、`=`、`#`、中文、空格和斜杠。
- 系统日志新增 tail/cursor 模式：首次读取尾部，后续增量读取，并处理 UTF-8 分段、未结束行、轮转、copytruncate、短读、超长行和非法 cursor。

## 构建与缓存

- mind-map 的 JS、CSS 和抽取 inline 脚本使用内容哈希文件名。
- `/admin/mindmap/index.html` 使用 `no-store`，哈希资源使用一年 immutable 缓存；iframe 不再生成时间戳 URL。
- admin 构建通过临时 shell 同步 mind-map 产物，不再覆盖仓库中的 `mind-map/index.html`。
- all-in-one Dockerfile 将 manifest / lockfile 依赖安装层放在源码 COPY 前；实测源码变化后 `pnpm install` 层继续命中 BuildKit 缓存。

## 安全与兼容性

- 登录失败保护现在使用 `maxRetryTimes`、`durationSeconds` 和对应缓存 TTL；非法配置回退到 3 次 / 60 秒。
- 主站默认数据库仍是 PostgreSQL 16，缓存与协调使用 Redis 7；Mongo 相关名称仅保留为旧 provider/schema/备份兼容接口和 Waline 可选 legacy 路径。
- PostgreSQL 启动时会自动增加文章搜索列和索引，并仅对缺失或过期的搜索向量执行幂等回填，无需人工迁移。
- 无新增必填环境变量，Compose 拓扑不变，可直接从 `v1.8.4` 升级。
