# v1.7.3

`v1.7.3` 是一次前台阅读体验的小幅打磨版本，只动文章页底部的「相关文章 / 最新文章 / 热门文章」三块，聚焦两件事：标题**单行省略 + 悬停浮出完整标题**，以及把三块从**三列并排改为从上到下堆叠**。

如果只用一句话概括：

> `v1.7.3` 让文章底部三块的标题像正文标题一样单行显示、鼠标悬停才浮出全称，并把三块竖直堆叠占满整行，修掉了此前三列过窄时分类标签被挤成竖排（「计 算 机 学 习」）、观感参差的问题。

## 本版摘要

- **标题单行省略 + 悬停气泡**：三块列表的文章标题不再折行，超长时以省略号收尾；只有真正被截断的标题，鼠标悬停才浮出一个完整标题气泡。气泡走 portal 挂到 `body`，不会被卡片的 `overflow-hidden` 裁剪，明暗两色都适配，且只读、不拦截点击（点标题照常跳转）。
- **三块改为竖直堆叠**：底部三块由 `lg:grid-cols-3` 三列并排改为从上到下 `space-y-4` 堆叠，每块占满整行宽度。行内空间充足后，右侧的分类标签恢复正常单行显示，不再在窄列里被挤成逐字竖排。

## 相比 v1.7.2 的变化

- 文章底部三块标题统一单行、超出省略；悬停被截断的标题显示完整全称。
- 三块从横向三列改为纵向堆叠，分类标签不再竖排。
- 其它文章列表页（时间线 / 归档 / 分类 / 标签 / 搜索）行为保持不变——单行省略仅作用于底部这三块。

## 升级建议

升级到 `v1.7.3` 后，建议重点验证：

1. 打开任意一篇文章翻到底部，三块「相关 / 最新 / 热门」从上到下堆叠、各占整行。
2. 长标题单行省略；悬停被截断的标题浮出完整标题气泡（明暗两色都清晰、不被卡片裁剪）；点标题正常跳转。
3. 右侧分类标签单行显示，无竖排。
4. 时间线 / 归档 / 分类 / 标签 / 搜索页的文章列表标题行为与升级前一致。

## 回滚方法

纯前台改动，把 release suffix 改回上一版并重新 `docker compose -f docker-compose.image.yml up -d` 即可，不涉及数据与配置迁移。

锁版镜像部署：

```env
VANBLOG_DOCKER_REPO=kevinchina/deeplearning
VANBLOG_RELEASE_SUFFIX=v1.7.3-<image-id>
```
