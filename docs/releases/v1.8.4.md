# v1.8.4

`v1.8.4` 是一次 Markdown 主题与首页预览体验修复版本，新增与 AgentObservatory 风格一致的 Vanblog Plain 经典主题，并修复暗色首页预览文字颜色、主题装饰残留和卡片底部空白问题。

## 修复内容

- Vanblog Plain（朴素/经典）改为独立的亮色/暗色主题资源，不再以空主题方式回退。
- 暗色 Plain 使用 AgentObservatory 的深色色板：`#0d0f0e` 背景、`#f1f3ef` 正文、`#6e9ff8` 强调色和半透明蓝色选中效果。
- Plain 主题不再加载 Vanblog 共享 Markdown hotfix，移除标题渐变、左侧装饰线、底部装饰线和主题化 hover 效果。
- 修复暗色首页预览卡片正文回退为灰色的问题，确保首屏和页面导航返回后的文字颜色一致。
- 修复 Plain 主题将完整文档编辑器的 `100px` 底部留白带入首页预览卡片的问题。
- 后台主题选择器说明同步更新，明确 Plain 的经典 Markdown 排版与亮暗高对比特性。

## 兼容性与升级

- 无数据库迁移。
- 无新增环境变量要求。
- Compose 拓扑不变。
- 可直接从 `v1.8.3` 升级到 `v1.8.4`。

- Website 主题资源、首屏同步测试：11 个测试通过。

- Admin 生产构建通过。
