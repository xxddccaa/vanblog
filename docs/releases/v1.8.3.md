# v1.8.3

`v1.8.3` 是一次 Markdown 数学公式与部署稳定性补丁发布，统一支持 LaTeX `\\(...\\)` / `\\[...\\]` 分隔符，并修复代理环境下拆分 Compose 栈的健康检查与服务间通信问题。

## 修复内容

- 前台、后台编辑器、文档预览与文章导出统一识别 `\\(...\\)` 行内公式和 `\\[...\\]` 块级公式。
- 保留公式中的 LaTeX 反斜杠、换行、Markdown-like 内容，不误处理代码围栏、缩进代码和行内代码中的字面量。
- 修复 server 处理单行块公式时吞掉公式后同一行正文的问题。
- 保持既有 `$...$` / `$$...$$` 数学公式语法兼容。
- Compose 健康检查使用 `wget -Y off`，避免 Docker daemon 注入 HTTP 代理后将本地健康请求发往错误代理。
- 拆分栈服务显式配置内部服务域名的 `NO_PROXY` / `no_proxy`，避免 server、website、Waline 和 Caddy 的内部请求错误走外部代理。
- 补充本机测试环境路径 A 文档：宿主机编译产物挂载到独立 all-in-one 测试环境，快速完成代码验证。

## 兼容性与升级

- 无数据库迁移。
- 无新增环境变量要求。
- Compose 拓扑不变；新增的是代理环境下的内部通信兼容性配置。
- 生产部署继续推荐 `docker-compose.image.yml` 锁定本次发布镜像。
- 可直接从 `v1.8.2` 升级到 `v1.8.3`。
