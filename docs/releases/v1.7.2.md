# v1.7.2

`v1.7.2` 是一次质量与体验修正版本，聚焦四件事：修复前台的 React 版本错配（连带解决字体双渲染与 hydration 报错）、治理生产环境日志、把字体作用域从"仅正文"扩展到"整个阅读内容区 + 后台编辑器预览"、修复目录与 Markdown 行内指令的渲染问题。

如果只用一句话概括：

> `v1.7.2` 让前台跑在正确的 React 19 上（字体不再重复注入、控制台不再报 hydration 错），生产 `docker logs` 与磁盘日志不再被刷爆，字体统一覆盖主页/列表/标题等所有可读内容（导航等 UI 仍用系统字体），并修好 `:GPT` 这类行内文本被误当指令吞掉的问题。

## 本版摘要

- **React 19 对齐**：`packages/website` 之前钉 React 18.2，而 Next 16 内置并使用 React 19，双版本共存导致字体样式被服务端提升到 `<head>`、客户端又在 `<body>` 重复注入（FontStyle "渲染两次"）+ 文章页 hydration `#418`。升级 `react`/`react-dom` 到 `^19` 并对字体 `<link>/<style>` 使用 React 19 的 `precedence` 资源提升，双渲染与 `#418` 消除。
- **生产日志治理**：
  - 修复 all-in-one 下 server 仍连 `http://waline:8360` 的错配（`VAN_BLOG_WALINE_API_URL` 现指向本机）——**评论数从此能正常获取**，并消除每次看文章刷 `ENOTFOUND waline` 的 WARN；
  - 服务端日志级别可配（`VAN_BLOG_LOG_LEVEL`，默认 balanced：error+warn+log，砍掉 debug/verbose 与启动路由表噪音）；
  - Caddy access log 跳过每 15s 的内部健康检查、并加大小滚动，`vanblog-access.log` 不再被健康检查刷爆磁盘；
  - Redis 默认 `loglevel warning`（压掉每 5 分钟 RDB 存盘流水）；
  - 所有 compose 加 `json-file` 轮转（`max-size 10m × max-file 3`）；`vanblog-stdio.log` 加大小上限。
- **字体作用域扩展**：`scope='body'` 从只作用 `.markdown-body` 扩展到内容容器 `.vanblog-main` + 正文——覆盖主页/列表预览卡片、文章标题、归档/分类/标签列表、关于页；导航栏/侧栏/页脚/搜索等 UI 仍用系统字体，内容区内的按钮/输入框也还原为系统字体（"读的地方套字体、点的 UI 不套"）。后台编辑器 markdown 预览也套上同款字体（所见即所得）。
- **目录（TOC）与 Markdown 渲染修复**：目录组件优化；`remark-directive` 会把 `:GPT` 这类"冒号紧跟字母"的行内片段误解析成文本指令、渲染成空 `<div>` 导致丢字与意外换行——现在按源码偏移还原为普通文本（含回归测试）。
- 一批数据一致性修复：归档按月列表在月份边界丢文章、标签页子串误匹配导致列表与计数不一致等。

## 相比 v1.7.1 的变化

- 文章页控制台不再有 `#418`，字体样式标签不再重复。
- 主页/归档/分类/标签页的文章标题与预览也用上所配字体（此前仅文章正文）。
- all-in-one 部署的评论数显示恢复正常。
- `docker logs` 稳态基本安静；`/var/log` 与容器日志都有大小上限。

## 新增可选环境变量（均有开箱即净默认值）

```env
# 服务端日志级别：silent | balanced(默认) | verbose
VAN_BLOG_LOG_LEVEL=balanced
# Redis 日志级别（默认 warning）
REDIS_LOGLEVEL=warning
# all-in-one 内 Waline API 地址（默认已指向本机，一般无需改）
VAN_BLOG_WALINE_API_URL=http://127.0.0.1:8360
```

锁版镜像部署：

```env
VANBLOG_DOCKER_REPO=kevinchina/deeplearning
VANBLOG_RELEASE_SUFFIX=v1.7.2-<image-id>
```

## 升级建议

升级到 `v1.7.2` 后，建议重点验证：

1. 文章页浏览器控制台无 `#418`，字体 `<link>` 每种只一份（在 `<head>`）。
2. 主页/列表预览卡片、文章标题、归档/分类/标签列表字体与正文一致；导航栏/侧栏/页脚仍是系统字体；代码块仍等宽。
3. 后台编辑器预览区字体 = 前台正文字体。
4. all-in-one 下文章评论数正常显示。
5. `docker logs` 稳态无 Redis 存盘流水、无 `ENOTFOUND waline`；`vanblog-access.log` 不再记录健康检查。

## 回滚方法

把 release suffix 改回上一版并重新 `docker compose -f docker-compose.image.yml up -d` 即可。字体设置与日志级别均存于配置/数据库，回滚镜像不丢设置；旧镜像不读新配置时自动回落默认行为。
