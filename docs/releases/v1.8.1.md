# v1.8.1

`v1.8.1` 是一次前台首屏样式补丁发布，重点修复网络较慢时 Markdown 富内容页面先显示无主题内容、随后再切换到正确样式的闪屏问题。

## 修复内容

- Markdown 明暗主题 CSS 与 hotfix 样式改为 React 19 stylesheet resource，由服务端渲染阶段提升到 `<head>`，浏览器会在首次绘制前加载富内容页所需样式。
- 保证 hotfix stylesheet 位于明暗主题 stylesheet 之后，继续维持既有覆盖顺序。
- 兼容 React 19 按 `href` 保留 stylesheet resource 的行为：富内容页切换到普通页面时禁用主题资源，主题 URL A → B → A 切换时只启用当前资源。
- `Layout` 卸载时统一禁用保留的主题资源，避免导航到 `notFound()` / 404 等不渲染 `Layout` 的页面后，自定义主题中的 `html`、`body`、`:root` 规则继续污染页面。

## 用户体验

- 慢速网络下打开首页、文章页等富内容页面时，不再先看到未应用 Markdown 主题的卡片或正文。
- 暗色模式的文章预览文字在首屏即使用正确颜色，不再等待客户端补载 CSS 后才恢复。
- 富内容页、普通页面、404 页面以及不同自定义主题之间导航时，不再残留上一页的主题样式。

## 兼容性与升级

- 无数据库迁移。
- 无环境变量变更。
- 无 Compose 拓扑变更。
- 可直接从 `v1.8.0` 升级到 `v1.8.1`。

## 验证

- Website 相关单元测试覆盖 SSR stylesheet 提升、hotfix 顺序、富内容/普通页切换、主题 URL A → B → A 与 `Layout` 卸载清理。
- Website 生产构建通过。
- 完整发布门禁 `pnpm test:full` 通过。
