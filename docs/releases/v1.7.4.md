# v1.7.4

`v1.7.4` 是一次后台编辑器体验的小幅增强版本，只动 ByteMD 编辑器：新增「预览联动高亮」——鼠标悬停左侧 Markdown 源码时，高亮右侧预览中对应的块，并把它做成可开关的偏好设置。

如果只用一句话概括：

> `v1.7.4` 让你在编辑器里把鼠标停在某一行源码上时，右侧预览中对应的标题 / 段落 / 列表项 / 引用 / 代码块 / 表格会被轻柔高亮；默认开启，不喜欢这种联动动效的用户可以在「操作 → 偏好设置」里一键关闭。

## 本版摘要

- **预览联动高亮**：鼠标悬停左侧源码块时，高亮右侧预览中对应的块。按「最小可读块」匹配——嵌套结构里优先命中范围最小、最具体的块（如引用内的整段引用、列表里的单个列表项、整段代码块）。目标完全滚出视口时，仅平滑滚动右侧预览容器进行定位，不打断编辑。
- **偏好设置开关**：在「操作 → 偏好设置」新增「预览联动高亮」项，默认开启。关闭后编辑器不再注入源码行标识、不再挂载鼠标监听、也不再有任何高亮，零开销。该设置保存在浏览器本地，与「保存后行为」「本地缓存」一致。
- **纯前端注入**：高亮只作用于后台编辑器预览，通过在预览节点上注入源码起止行标识实现，不改后端接口、不改文章 Markdown、不影响前台展示。明暗两色主题均适配。

## 相比 v1.7.3 的变化

- 后台 ByteMD 编辑器新增「源码悬停 → 预览联动高亮」，并提供偏好设置开关（默认开启）。
- 修复暗色模式下高亮描边颜色因复用通用变量而偏淡的问题，明暗两色描边现在都清晰可见。
- 仅涉及后台编辑器；前台阅读、文章内容与既有编辑器行为保持不变。

## 升级建议

升级到 `v1.7.4` 后，建议重点验证：

1. 打开任意文章 / 草稿编辑页，鼠标停在左侧不同源码行上，右侧预览中对应的块被高亮（标题、段落、列表项、引用、代码块、表格均可）。
2. 鼠标移出编辑区后高亮立即消失；快速移动、连续输入、长文滚动时表现正常。
3. 明暗两色主题下高亮都清晰、不干扰阅读。
4. 「操作 → 偏好设置 → 预览联动高亮」切到「关闭」后，悬停不再有任何高亮；切回「开启」后恢复。

## 回滚方法

纯后台前端改动，把 release suffix 改回上一版并重新 `docker compose -f docker-compose.image.yml up -d` 即可，不涉及数据与配置迁移。

锁版镜像部署：

```env
VANBLOG_DOCKER_REPO=kevinchina/deeplearning
VANBLOG_RELEASE_SUFFIX=v1.7.4-<image-id>
```
