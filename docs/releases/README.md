# 发布说明

这里收录当前仓库的重要版本说明与迁移指引。

- 默认维护分支：`master`
- tag 保持独立管理，不受分支切换影响
- 当前公开文档基线：`v1.8.6`
- AI 工作台自 `v1.4.0` 起成为正式能力，但依然保持为可选部署

## 关键版本

- [`v1.8.6`](./v1.8.6.md)：修复动态卡片继承 Markdown 主题底部画布留白的问题

- [`v1.8.4`](./v1.8.4.md)：Vanblog Plain 经典 Markdown 主题、暗色预览文字颜色与首页卡片留白修复版本
